# rc2.ini keys

Generated by `scripts/rc2ini_doc.py`; don't edit by hand. Every key of RC2's prefs table
(`dlls/rc2prefs_table.cpp`, 1113 keys in 23 headings), in the table's order, which is also the
order `rccfg save` writes them in. How the file is found, loaded and changed in game is in
[SERVER.md](SERVER.md#rc2ini).

Columns:

- **type**: how the value is parsed and held. `smallfloat` is a float held to 0..655.35 (it
  goes to clients as hundredths); `short` is held to -32767..32767, `ushort` to 0..65535,
  `byte` to 0..255; `bool` is true for `true`, `yes` or a nonzero number.
- **default**: the value the key has when the file doesn't set it. Every key goes back to
  its default at each map start, before the file is read.
- **shipped**: what RC2 beta 1.1's own `rc2.ini` sets, as the file writes it. Blank: the
  file doesn't set it. A value the loader changes is shown as `text -> kept`.
- **flags**: the clamps applied after parsing, in this order: POS_ONLY (below 0 becomes 0),
  THREE_DIGITS (held to 0..999), ZERO_TO_ONE (0..1), NEGATIVE_ONE_TO_ONE (-1..1), FOUR_DIGITS
  (0..9999), GREATER_THEN_ONE (below 1 becomes 1), NOT_ZERO (0 becomes 1). On a `byte` or
  `bool` the below-0 and above-255 tests can't fire; a `ushort` is clamped as a signed
  short, so 32768 and up count as negative. REGISTER_ITEM_INFO: changing the key in game
  re-reads the 14 stock weapons' item info (slots, maximum ammo).
- **sent**: `yes` for the NETWORK_SYNC keys, which the client library also reads. A
  joining client gets every one that isn't at its default, and `rccfg setkey` sends the
  new value to everyone.
- **read in**: the files that name the key (`(cl)`: the client library). Blank: no code
  in the rebuild reads it.
