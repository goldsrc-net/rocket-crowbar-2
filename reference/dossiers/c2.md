# c2: client.dll .text 0x4ec50-0x71ad0 (ammohistory, battery, cdll_int, the first part of RC2's client effects)

## Scope

Original files: ammohistory (all stock, nothing to do), RC2's attribute file between ammohistory and
battery, battery, cdll_int (with the CHud constructor and the HUD elements' inline destructors it
emits for gHUD), and the start of RC2's one big client effect file ("CLTE", client temp entities),
0x508e0 to 0x71ad0. The rest of that file, from 0x71ad0 (the shield's DrawTransparent, CLTE 0x26-0x49),
is c3's.

Written here (names ours, client.dll keeps none):

- `cl_dll/rc2/attributes.cpp`: SetAttr, every player's attributes, the client side of the pm hooks
  (pm_rc2.h), a scientist.mdl sequence remap nothing calls.
- `cl_dll/rc2/clte.h`: CClientTent and CClientTentCmd, the manager API, the shape/strip API,
  CTentTrail, CTentParticles, inline helpers.
- `cl_dll/rc2/clte_types.h`: the effect classes the manager reaches into (CLTE 3, 5) and, as far as it
  uses them, four of c3's (0x29, 0x39, 0x3b, 0x41), with the Create declarations of CLTE 0x26-0x49.
- `cl_dll/rc2/clte.cpp`: the "CLTE" handler, reset/shutdown/update/draw passes, per-player overrides,
  the loopback buffer, the origin cache, the shield intersection.
- `cl_dll/rc2/clte_draw.cpp`: animating disks, fade quads, beam quad and the four strip drawers.
- `cl_dll/rc2/clte_particles.cpp`: CTentTrail, CTentParticles, three point callbacks.
- `cl_dll/rc2/clte_effects1.cpp` (CLTE 1-9), `clte_effects2.cpp` (10-12), `clte_effects3.cpp` (13-20),
  `clte_effects4.cpp` (21-37).

Changed: `cl_dll/battery.cpp`, `cl_dll/cdll_int.cpp`; shared, `pm_shared/pm_shared.cpp` (only its
CLIENT_DLL stub block: the six hooks now real in attributes.cpp removed).

## Status

Built, not run in an engine. `scripts/build.sh i386 client` and `scripts/build.sh i386` build.
check_coverage --lib client, 0 missing in 0x4ec50-0x71ad0:

```
ammohistory                       stock (all matched)
new: ammohistory .. battery       6 of 6
battery                           matched + 0x4f840/0x4f940 tagged
new: battery .. cdll_int          3 of 3
cdll_int                          8 of 8
new: cdll_int .. com_weapons      180 of 313 (the 133 left are 0x71ad0 on, c3's)
```

55 functions Ghidra missed (found as incremental-link thunk targets not in files-client.tsv; most
are effect vtable slots: Update, KillEntity, Draw) are reconstructed and tagged too, though
check_coverage doesn't count them (no gaps-client.tsv). Compiler-generated functions (gHUD's
initializer and atexit, CHud::CHud, 17 element destructors and their 17 deleting destructors, the
disk/quad arrays' constructors, empty dynamic initializers, CTentTrail's vector deleting destructor,
out-of-line Vector operators) are tagged in comments where they arise.

Method: decompile where readable; the disassembly (frame-annotated: locals, args, API slots, prefs)
for gap functions and wherever Ghidra garbled Vector temporaries, which is most effect code. CLTE
13-20 and 21-37 were done by two forks of this agent on the same method.
