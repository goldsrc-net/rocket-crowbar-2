# p4: hassassin.cpp through mp5.cpp (rc2.dll .text 0x5cdc0-0x7df80)

## 1. Scope

The original's files in this range (link order): hassassin, headcrab, healthkit, hgrunt, hornet,
RC2's freeze grenade, hornetgun, houndeye, ichthyosaur, interface (CreateInterface), islave,
items, RC2's LCS scripts, leech, lights, maprules, RC2's alteration expressions, monstermaker,
monsters, monsterstate, mortar, RC2's MP5 bolts, mp5, and the first static initializers of
multiplay_gamerules. 328 functions to reconstruct (82,739 bytes).

Written or changed here (worktree `~/Projects/goldsrc.net/mod-rc2-wt/p4`, uncommitted):


Method: every function was compared with its SDK 2.3 counterpart in the RC2-layout VC6
reference build (`build-vc6/hl-rc2`), instruction by instruction with names, strings, floats,
rc2.ini keys and g_engfuncs slots resolved, which separates layout-only differences from RC2's
own. Functions with no counterpart, and the ones Ghidra didn't export, were read from the
disassembly; the decompile was used where it was coherent. The tools are helper
scripts kept outside the repo: scan, diff and disassembly against the reference; disassembly with
offsets and names; decompile by address with rc2.ini and engine names; which vtables hold an
address; rc2.ini key lookup.
