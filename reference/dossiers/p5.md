# p5: multiplay_gamerules to player (rc2.dll .text 0x7df80-0x9f2a2)

## Scope

Original files: multiplay_gamerules, nihilanth, nodes, osprey, pathcorner, plats, player, and the
runs of RC2's code between them (the nuke between nodes and osprey; small virtual overrides and
compiler-emitted constructors elsewhere). LinkUserMessages, in player.cpp in SDK 2.3, is in
halflife-updated's UserMessages.cpp.

Written or changed here:

- `dlls/multiplay_gamerules.cpp`, `dlls/nihilanth.cpp`, `dlls/nodes.cpp`, `dlls/nodes.h`,
  `dlls/osprey.cpp`, `dlls/pathcorner.cpp`, `dlls/plane.cpp`, `dlls/plats.cpp`, `dlls/trains.h`,
  `dlls/player.cpp`, `dlls/player.h`, `dlls/UserMessages.cpp`, `dlls/UserMessages.h`
- new: `dlls/rc2/nuke.cpp` (CNuke, nuclear_missile), `dlls/rc2/p5_externs.h` (what player.cpp
  uses from other packages)
- shared files, in marked `// p5 needs:` blocks only: `dlls/cbase.h` (CBaseEntity),
  `dlls/gamerules.h` (CGameRules, CHalfLifeMultiplay), `cl_dll/hl/hl_baseentity.cpp` (client
  stubs for two new CBasePlayer virtuals)

"RC2's changes" in short, per function (the comment above each function in the source says the
same):

- multiplay: Think (mp_chattime at least 10; mp_scoremode 1 applies the frag limit to the
  damage score, frags left "%.2f"); FShouldSwitchWeapon (userinfo noautoswitch); InitHUD (six-byte
  ScoreInfo, each player's score twice, the damage score as a long with index | 0x80, no MOTD);
  PlayerKilled (IsPlayer instead of Classify, energy for a kill, damage scores, no satchels);
  DeathNotice (DeathMsg carries a death message number and the victim's gender, dedicated server
  prints the text); PlayerSpawn (crowbar plus the weapons in m_iSpawnWeapons with rc2.ini extra
  ammo); GoToIntermission (chattime 10); ChangeLevel (bootcamp).
- nihilanth/osprey: GetRCCaps/GetRCCaps2/damage getters; ZapThink hits GetEffectedEnt;
  COsprey::Flight lost the rotor pitch shift against the first player.
- plats: CPlatTrigger::Touch asks IsActivePlayer; CFuncTrain and CFuncTrackTrain Blocked give a
  gauss_becon a fixed 2 crush damage through GetEffectedEnt.
- player: see the per-function comments; the large ones are TakeDamage, Killed, PreThink,
  PostThink, Spawn, UpdateClientData, PlayerDeathThink, WaterMove, SetAnimation.
