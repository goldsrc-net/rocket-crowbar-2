# p1: rc2.dll .text 0x1000-0x2ae06

## Scope

The original's files from the start of .text through the edge of crossbow.cpp (PACKAGES.md,
section p1). Here that covers:

- RC2's own code before aflock.cpp, written as **dlls/rc2/maintainent.cpp** (new). It holds the
  admin commands, LCS entity scripting, the admin camera and CMaintainEnt.
- SDK files changed: aflock, agrunt, airtank, animating, animation, apache, barnacle, barney,
  bigmomma, bloater, bmodels, bullsquid, buttons, cbase, client, combat and controller.cpp, each
  in place in `dlls/`.
- RC2's own runs between those files:
  - **dlls/rc2/antifrictimer.cpp** (CAntiFricTimer), in the animation..apache run.
  - **dlls/rc2/crossbowbolts.cpp** (CImpailer, CXBowTeather, CExplodeBolt), in the
    controller..crossbow run.
  - The other runs are edge functions of the SDK files and live in those files.
- Shared headers, touched only inside `// p1 needs:` blocks: cbase.h, basemonster.h, player.h,
  weapons.h, talkmonster.h and gamerules.h.
- crossbow.cpp (p2's): only the orig comment on `LINK_ENTITY_TO_CLASS(weapon_crossbow)`.

Forks did part of the work, and their reports are merged here:
- Fork A: aflock through barney.
- Fork B: bigmomma through buttons.
- Fork C: controller through crossbow.

The parent did maintainent, cbase, client and combat.

## Status

`scripts/check_coverage.py <label> --missing` gives 0 missing on every p1 label (467 of 467
functions). The per-label results are in the final report.

Beyond the list, about 25 KB of code sits in unlisted gaps, where Ghidra made no function. Each
gap was identified and is reconstructed or annotated:
- ClientCommand (6 KB), ClientDisconnect, ClientKill, ClientUserInfoChanged, AddToFullPack,
  GetWeaponData, UpdateClientData, StartFrame, ServerDeactivate, FireBulletsPlayer, DispatchUse.
- The LCS token callbacks at 0x1670 and 0x2370, plus 0x14c0, 0x28a0 and 0x2c70.
- CMaintainEnt::Spawn (0x4d90).
- Stock functions: CGib::SpawnStickyGibs and SpawnHeadGib, Entity/Player_Encode, the
  Spectator* functions, ConnectionlessPacket, Sys_Error, AllowLagCompensation.
- The jump tables in bigmomma and bullsquid.

`scripts/build.sh` builds i386 (hl and client) and amd64 (hl). "Built" is all that can be claimed:
nothing has been run in an engine against the original.

Method:
- **Stock:** a function is stock when its normalized disassembly matches the hl-rc2 reference
  build's function of the same name. It then carries only `// orig 0x... (stock)`.
- **Changed:** a changed function started from halflife-updated's body and was edited to match
  RC2's decompile and disassembly.
- **Tools:** the scratchpad helpers used (pp.py, da.py, cmp.py, gaps.py) aren't in the repo.

CBaseEntity's added members, and what p1's code does with each (the names stay neutral):

- **m_iRC2Base64** (+0x64) is really bytes. +0x66 is frozen (p1 adds m_fRC2Frozen, p4's name)

  - 0x10: sent to dmg_inflictor, invisible
  - 0x20, on the host: sees DAMAGE_AIM entities, out of sight as position only
