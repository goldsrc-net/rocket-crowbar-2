The key finding: RC2's viewport is not SDK 2.3's. It is SDK 2.1's (the one Ricochet still ships,
`hlsdk/ricochet/cl_dll`): one command menu from commandmenu.txt, the spectator "menu" of three
labels, the server browser, with SDK 2.3's team menu and scoreboard, TFC's class code removed,
and RC2's own vote box, player name label and debug panel. Ricochet's source was the reference
for those functions; SDK 2.3 (build-vc6) for the rest; every function was diffed against one.
RC2's CommandButton also predates m_iPlayerClass and m_bFlat.

The ones left, explained:

- **vgui:vgui.dll (190) and 24 of "vgui:vgui.dll .. libcmt:ftol"**: 6-byte `jmp [__imp_...]`
  import thunks for vgui.dll and wsock32.dll (Ordinal_9). The linker's, like the incremental
  thunks check_coverage already skips; it should skip `ff 25` thunks too.
- **0xee4d0, 0xee500, 0xee510, 0xee560**: the C runtime's floating point init
  (`__ms_p5_mp_test_fdiv`, `_cfltcvt` table, `__setdefaultprecision`) and a handler setter,
  between RC2's code and libcmt's ftol. Not RC2's.
- **0xd9330, 0xd9350, 0xd9370, 0xd93a0** (vgui_int) and **0xe3d90, 0xe4030** (viewport): the
  compiler's Layout/BorderLayout and vgui::MenuSeparator copy constructors, operator= and
  destructor, generated from the VGUI headers. Noted at VGui_Startup.
- **0xe6d60**: an inline handler (`(+4)->vfunc 0x1fc(+8)`) with no caller and no vtable
  reference. The coordinator says c4 implemented the check-button/spinner inlines at
  0xe6c20-0xe6c80 and 0xe6d60; I didn't write it.

Built: `scripts/build.sh i386 client` and `scripts/build.sh i386` pass. Nothing has run in an
engine.

## 8. Original bugs (kept)

- MsgFunc_VoteBegin dereferences m_pVoteMenu when ShowVGUIMenu returned early (demo playback):
  NULL crash.
- Several setText calls pass player names, vote text and localised strings as the format
  (UpdateSpectatorMenu, VoteBegin/SetVoteText, PlayerID, VoteUpdate): a '%' in them misprints.
- RecalculateText prints a bound key of (char)255 as a character.
- CreateCommandMenu frees the advanced parse pointer, not the loaded file (as SDK).
- ShowVGUIMenu: a menu queued behind a non-class menu skips UpdateCursorState.
- V_StartViewShake draws frequencies with RandomFloat(1.2566, 1.0472), low above high.
- V_UpdateScreenTint's clamp to 255 compares the truncated byte, so never applies.
- V_GetInEyePosition scales pitch by -pi (SDK 2.3: -3).
- View mode 2 stale basis vector (VERIFY 7).
