# reference/ - original Rocket Crowbar 2 artifacts

Source-of-truth binaries from the original mod, kept for reconstructing the server
and client libraries as C++ on this SDK. Reference only, not linked into any build.

The original libraries themselves are not in this repository: they are their authors' work. Put
them here, under the names below (the checksums say which files), before running the scripts and
the test rig that read them; they are in the beta 1.1 and beta 1 installers (Provenance). `.gitignore` keeps them out of commits.

RC2 never had a Linux build, so unlike RC 1.9 and The Specialists there is no
unstripped .so: these Windows libraries are all there is.

| File | What it is |
|---|---|
| `rc2.dll` | Beta 1.1 server library, MSVC, built 2004-01-12 00:56 UTC. No PDB (only its path, `C:\SIERRA\Half-Life\RC2dev\dlls\Releasehl\hl.pdb`), no RTTI. 352 mangled exports (save/restore callbacks, fully typed once demangled), 301 unmangled (entity classnames, engine API), 529 save/restore field names in its strings. |
| `client.dll` | Beta 1.1 client library, MSVC, built 2004-01-11 23:53 UTC. No debug directory; its exports are mostly VGUI templates. |
| `beta1/rc2.dll`, `beta1/client.dll` | The same libraries from beta 1 (built 2004-01-03), for diffing. Per the changelog, 1.1 fixed the menuconfig load/save crash and the forklift jump command. |

Generated by `./dump-signatures.sh` (needs llvm-undname and binutils), per library:
`exports-<lib>.raw`, `signatures-<lib>.txt`, `entities-<lib>.txt`, plus
`fields-rc2.txt` and `classes.txt`.

Beta 1.1 is the last public release. Its DLLs are byte-identical in a beta 1.1 server
install and in `rc2beta1.1.exe` from the Wayback Machine
(`rocketcrowbar.com/downloads/rc2beta1.1.exe`, archived 2004-02-11). Beta 1 is
`rc2beta1.exe` (24,470,957 bytes). The two installers' content is otherwise
identical apart from beta 1's redundant pak0.pak and 1.1's changelog.txt and rc2.ini.
