## For DEVIATIONS.md

- **`CmdStart` and `CmdEnd` cast the player with `dynamic_cast`** (`dlls/client.cpp`, halflife-updated),
  so their existing NULL check also catches an edict that isn't a CBasePlayer.
- **`ReportAIState` names all nine monster states** (`dlls/monsters.cpp`, halflife-updated): SDK 2.3's
  list has no "PlayDead", so it printed "Dead" for a playing-dead monster and read past the list for
  a dead one. Nothing in our tree calls it (SDK 2.3's impulse 103 did, in player.cpp; ours has no
  such call), so it shows nowhere today.
- **`func_plat`'s trigger holds its platform by handle** (`dlls/plats.cpp` `SpawnInsideTrigger`,
  halflife-updated): a removed platform no longer leaves the trigger reading freed memory.
- **Monsters take an `allow_item_dropping` keyvalue** (`dlls/monsters.cpp` `KeyValue`, from Opposing
  Force Updated): no RC2 map sets it (none of the 15 .bsp files in the install has the string), and
  unset it keeps the drops.

## Odd

- `CApache::NullThink` (0xaec0) is tagged `(stock)` and is the SDK's body, but it isn't in
  `names-rc2.tsv`, so stock_drift never listed it. Other stock functions missing from the matcher's
  table would hide halflife-updated changes the same way.
- `CGrenade::ShootTimed` carried a comment from an earlier pass that kept halflife-updated's
  ResetSequenceInfo on purpose. The new policy reverts it; the comment is gone.
- `CBaseMonster::m_flLastYawTime` (basemonster.h) is now unread. Left in place: its header isn't mine,
  and halflife-updated's flying monster and ichthyosaur pitch code came in the same commit (343bbb2),
  in other packages' files.
- halflife-updated's ChangeYaw fix exists because monsters turn by the server frame time: on a high
  sys_ticrate server they turn slower than at the 2004 defaults. That is the original's behavior on
  today's engine too, so it is reverted, but it is the one revert a server admin may notice.
- `stock_drift.py --sdk build-vc6/singleplayer` (BRIEF.md's command) doesn't work from a worktree:
  `build-vc6/` exists only in the main checkout, and the script then reports every function as "not in
  base". Pass `--sdk ~/Projects/goldsrc.net/mod-rc2/build-vc6/singleplayer`.
